  1. 取公开件：打开索引页 https://zhaoxinghua09-cell.github.io/uibc-ip-standing/，或直接下载 attest/ROOT.txt；不想装工具就开 verify.html（浏览器内跑 8 项）。
    想用命令行，三行可复制（无 git、只下载 zip；实测 2026-11-27 于干净机器 4.42 秒）： 
    curl -sL -o pack.zip https://codeload.github.com/zhaoxinghua09-cell/uibc-ip-standing/zip/refs/heads/main
python3 -c "import zipfile;zipfile.ZipFile('pack.zip').extractall('.')"

    预期末行 结论：PASS（10 项通过/警告，0 项失败）。
  2. 自己核两条：
    • sha256(ROOT.txt) 是否等于上表的 dda8ccf1…（一条命令即可）；
    • 任取一个区块高度，到 blockstream.info 和 mempool.space 各查一次，两源区块哈希是否一致（两边都查，才叫独立）。
  3. 给出回执：把下面这份 JSON 填好，直接点这里新建 Issue（标题自动带 witness:，正文粘 JSON 即可），或在任何可公开引用的地方发布并留下链接。
    只需改三处：witness（你的名字或机构）、checked_at_utc（你核对的 UTC 时间）、block_hash_observed（你在浏览器里看到的哈希）。若你算出的值与上表不同，请把差异一并写进回执——那才是最有价值的一份。回执不需要你担保文件内容，只担保"你在某个时刻亲眼核到了这些数值"。

三、回执格式（最小可用）

字段对齐仓内 attest/WITNESS_RECEIPT_TEMPLATE.json：

{
  "witness": "<你的名字或机构>",
  "witness_independence": "<说明你不受出具方雇佣/控制>",
  "checked_at_utc": "<你做核对的 UTC 时间>",
  "root_txt_sha256_observed": "<你算出来的值>",
  "merkle_root_observed": "<你从页面抄下/接口取到的值>",
  "block_heights_checked": [977354],
  "block_hash_observed": "<你从区块浏览器看到的哈希>",
  "sources": ["<你用的两个区块浏览器链接>"],
  "statement": "我核对了上述数值彼此一致，未核对原始文件内容。",
  "public_url": "<这份回执的公开链接>"
}

收到后我们会把它登记进 WITNESS_LEDGER.jsonl（只增、带哈希链），并在索引页显示回执数。回执一经登记，就可以被他人拿来与本仓数值对账。

四、见证人应满足什么

  • 独立：不隶属于出具方，也不受其控制；可以是律所、审计机构、客户、同行研究者，或个人。
  • 可被引用：回执必须有一个公开可访问的地址（Issue、博客、公证存档均可）。
  • 只核数值，不背书内容：不要求你判断文件内容合法或权属归谁。
  • 不需要交出任何私密信息：核对全程只用公开件；不要把私钥、内部路径、客户资料带进回执。
