如何复验

  • 浏览器内（零安装）：打开 verify.html —— 逐项跑 sha256、Ed25519 验签、Rekor 查询，全在本机浏览器完成
  • 要一份可打印件：打开存证证书（A4，可另存 PDF）
  • 想当见证人：三步给出你自己的回执（当前回执 0 条，欢迎第一个）
  • 零依赖：python verify_offline.py <解压目录> # 期望 grade=VERIFIED_STRUCTURE
  • 完整：python verify_pack.py <解压目录> # 期望 verdict=OK（需 cryptography 与 ots）
  • 外部核对：按 bitcoin_anchors 的高度到 blockstream.info / mempool.space 核对 block_hash 与 merkle_root
