## 二之二、首屏实测（2026-11-26）

不是凭感觉说"我们的页面不好懂"，是抓了竞品首屏文字来比：

- `opentimestamps.org` 首屏可见：`Stamp and Verify` → `Use the in-browser stamper and verifier`（一句动作指令）
- `tsa.cn` 首屏可见：`立即下载` / `立即取证` / `立即保护` / `立即认证` / `立即签署` / `立即监测`（六个动作按钮，全部动词开头）
- 我们（改前）：`merkle_root` / `root_txt_sha256` / `pack_id` … 七个字段加一张表，**零动作指令**

结论：**在"看得懂、点得动"这件事上，商业竞品早就做对了，我们落后得很晚才补。** 补法是把"先看这里"放首屏，并明说"看不懂数字没关系，判断有没有被改过靠 verify 页"。这条不算超越，算补齐基本功。

## 三、结论（不粉饰）

1. **我们赢在"验"，不在"用"**。任何人拿到仓库能在 1 秒内自证，这是 OTS 也没做到的（它要节点）。这是本套唯一真正的差异化。
2. **我们在"采信"这条线上是零**。tsa.cn 花 10 块钱买到的不是时间戳，是"法官愿意当庭登录这个网站"的既有事实。这东西买不到，只能靠案例积累，或者干脆走公证/TSP。
3. **拿本套替代取证平台是错的**。要打侵权取证，去 tsa.cn 或保全网（1 元/条 + 公证 800/份），比我们合适得多。
4. 所以对外定位只有一句：**"一份可以自己验、不依赖任何公司活着的存在性承诺件"**。凡是把它说成"电子证据平台""司法存证服务"的，都是在替我们吹牛。

## 四、本轮据此补的三件事

- 新增 `attest/VERIFY_RECEIPT.json`（机器可读回执，sha256 `736de856bd22a16a0fafee2fa87edb56add2868cc57faf147ed2b4fd11a36f0f`）：任何 CI、任何监控都能直接 diff 这份 JSON，而不必解析网页或 PDF。竞品没有对应物。
- 修掉一条**失效链接**：GlobalSign 时间戳产品页 `/en/timestamping` 现为 **404**，公开材料里改用其首页入口 + 注明 TSA 端点为 POST-only。
- 首屏加"先看这里"三步引导 + verify 页加"怎么用"一句：从"外人到站即停"变为"会点鼠标就能验"（这属于追平竞品，不属于超越）。
